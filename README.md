# RightCFD-InputDeck

## How to Run the Program

### 1. Install Kivy
- Ensure you have Python installed on your local machine (preferably Python 3.7 or higher).  
- Install the `kivy[base]` package using `pip`:
  ```bash
  pip install kivy[base]
  ```
- If you're working in a virtual environment (recommended), activate it before running the `pip` command:
  ```bash
  python -m venv myenv
  source myenv/bin/activate  # On macOS/Linux
  myenv\Scripts\activate     # On Windows
  pip install kivy[base]
  ```
- For detailed installation instructions, refer to the [Kivy installation guide](https://kivy.org/doc/stable/gettingstarted/installation.html).

---

### 2. Clone or Copy the Code onto Your Machine
- If the repository is hosted on GitHub:
  ```bash
  git clone https://github.com/your-username/RightCFD-InputDeck.git
  ```
- Alternatively, you can download the repository as a ZIP file from GitHub and extract it.

---

### 3. Navigate to the Project Directory
- Open a terminal or command prompt and navigate to the directory where the code resides:
  ```bash
  cd /path/to/RightCFD-InputDeck
  ```

---

### 4. Run the Program
- Execute the main script:
  ```bash
  python main.py
  ```
- The application should launch, displaying the Kivy-based GUI. Make sure all dependencies are installed.

---

## Additional Notes

### Operating System
- For the best experience, run the program on **macOS** or **Linux**. The program is tested and optimized for these operating systems.

---

### Exiting the Program
- Use `CTRL+C` in the terminal to safely terminate the program if necessary.
